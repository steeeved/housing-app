# Nyumba user stories

## Must have

- As a tenant, I want to filter homes by area and rent so that I only see homes I can afford.
- As a tenant, I want to message the agency about a home so that I can ask before I travel.
- As an agent, I want to sign in so that only my agency can change its homes.
- As an agent, I want to mark a home as let so that tenants stop asking about it.
- As an agency owner, I want to see all my agency's homes in one list so that I know what is available.

## Later

- As a tenant, I want a WhatsApp button so that I can reach the agency the way I already chat.
- As a visitor, I want a short page about the agency so that I know who I am dealing with.
