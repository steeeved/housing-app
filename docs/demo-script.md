# Demo script

Your demo is two minutes. Then you answer one question. Write each beat in your own words. Say it out loud and time it.

Use invented details only. Never show a password, a secret setting, a connection address or a cookie on screen. If a sign-in screen is on show, type the password off screen or have it filled in before you share.

| Beat | What you do | What you say (your words) |
|---|---|---|
| 1. Who it is for | Show the home page | Who uses Nyumba and what problem it solves |
| 2. Browse | Filter the homes | One filter, and what you expect to see |
| 3. Inquiry | Send an invented inquiry | What the visitor sees, and what the server did |
| 4. Sign in | Sign in as the fictional manager | Why a manager sees only their own agency |
| 5. One request journey | Point at the diagram or the code | The path from browser to server to database and back, for the inquiry |
| 6. The AI part | Show one prompt and one diff | One thing the AI did well, and one thing you had to fix |
| 7. Next | Say it | One thing you would build next |

## Questions to be ready for

- How does the app know who is signed in?
- What stops one agency seeing another agency's homes?
- What did you break on purpose, and how did you fix it?
- What would you change first if a real agency used it?
- What did the AI get wrong?

## If something goes wrong on the call

Say what happened in one sentence. Move to the recorded run or the screenshots. Carry on with the beat you were on.
